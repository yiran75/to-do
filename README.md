Features

Add tasks – Type in the input field or press Enter to add a new task
Mark as done – Clicking the checkbox marks a task complete and triggers an animated "DONE" stamp
Delete tasks – Each task has a delete button to remove it individually
Filter tasks – Switch between All / Open / Done tabs to view tasks by status
Progress tracking – A progress bar shows how many tasks have been completed
Clear finished tasks – One click removes all completed tasks at once
Persistent storage – Tasks are saved in the browser's localStorage, so data survives page refresh or closing the browser
Responsive design – Works well on both mobile and desktop screens
Custom UI theme – Postal-slip inspired design (typewriter font, perforated edges, rubber-stamp animation)
Accessible markup – Uses ARIA labels and a live region for screen reader support

Built with: HTML, CSS, JavaScript (vanilla, no frameworks)
